BOT TRADER SWING MULTI E8.4.0-dev2

1) Giải nén toàn bộ thư mục.
2) Cài Python 3.10+.
3) Chạy install_windows.bat (Windows) hoặc run_mac_linux.sh sau khi cài dependencies.
   Hoặc làm theo README.md để tạo virtual environment và cài requirements.txt.
4) Chạy: python -m streamlit run app.py
5) Kiểm thử: python -m pytest -q

Trạng thái: DEVELOPMENT. 150 automated tests passed; Streamlit runtime chưa được xác minh trong môi trường build.
Xem docs/RELEASE_STATUS_E8.4.0-dev2.md để biết giới hạn và các mục chưa nghiệm thu.
Dữ liệu dòng tiền OHLCV là proxy. App phục vụ học tập/nghiên cứu/mô phỏng, không tự đặt lệnh.
