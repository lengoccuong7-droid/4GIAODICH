# V6.3.1 – Diễn giải bằng ngôn ngữ tự nhiên

- Ưu tiên nhận định bằng câu văn ở tab Tổng quan và tab Dấu chân dòng tiền.
- Đưa điểm sàng lọc vào phần giải thích; làm rõ điểm 0 không phải xác suất thắng hay dữ liệu bằng 0.
- Diễn giải trạng thái VN-Index theo bối cảnh thuận lợi/rủi ro/trung tính/chưa đủ dữ liệu.
- Tách rõ bằng chứng, cảnh báo và điều kiện còn thiếu; không suy diễn OHLCV thành dòng tiền tổ chức.
- Giữ nguyên 3 tab, bộ máy phân tích và các quy tắc tính toán V6.3.0.
